The folder consists of the labelled data set of all JEE mains Physics question from 2002-2025
It also contains a small script to help you with your tests and scores
Run the main_app.py file to access the tests (Chapterwise and Full), currently only the console version is available for this.
The tests are mainly of 2 types, chapterwise and full. The code also calculates your strenght and weakness, and provided you with tests which help you focus on your weakness.
